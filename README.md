## 🚀 What is this?

This repository hosts the **public download page** for the MyStore Android app. It automatically fetches the **latest release** from the [releases repo](https://github.com/YOUR_USERNAME/mystore-releases) and shows a download button.

### ✨ Features

- 🔄 **Auto-updating** — Always shows the newest APK
- 📱 **Mobile-first design** — Beautiful on every screen
- ⚡ **Zero backend** — Pure static site, GitHub Pages powered
- 🎨 **Gradient UI** — Modern, clean, and fast
- 📊 **Live version info** — Size, publish date, changelog
